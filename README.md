# Attendance App (React + Node)

## Run panna
Terminal 1 (backend):
    cd server
    npm install
    npm start        # http://localhost:5000

Terminal 2 (frontend):
    cd client
    npm install
    npm run dev      # http://localhost:5173

## Demo logins
- Admin: admin / admin123
- Users: ravi / user123, priya / user123

Production la JWT_SECRET environment variable set pannunga.
